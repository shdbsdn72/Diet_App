# 온밸런스 · Onbalance

한국어로 사용하는 개인 웰니스 웹 앱. Node.js 22 이상에서 추가 패키지 없이 실행합니다.

```sh
npm start
# port 3000 (PORT 환경 변수로 변경 가능)
npm test
```

신체 정보와 목표 날짜, 체중 이력, 운동 추천 및 기록, 물 섭취, 보유 재료와 제외 재료 기반 레시피 추천, 식사 기록을 제공합니다. 모바일 화면을 지원합니다.

데이터는 브라우저 localStorage에만 저장합니다. 계정, 서버 데이터베이스, 기기 간 동기화, 외부 AI 연동은 아직 없습니다. 초기 냉장고 재료는 예시이며 삭제할 수 있습니다. 영양 정보는 레시피 1인분 기준 추정값이고, 추천은 일반적인 참고 정보입니다. 알레르기 원재료 확인이나 전문 의료 상담을 대체하지 않습니다.
